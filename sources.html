默认公开信息源

信源按“一手数据库和官方 feed 优先、稳定公开接口优先、单源失败隔离”组织。

论文与研究元数据

  • Europe PMC：论文标题、摘要、期刊、PMID / DOI 和发表日期。
  • Papers.cool：q-bio、机器学习、计算机视觉和医学物理 RSS；先通过 AI + 生物主题预筛，再进入统一评分。

临床试验注册信息

  • ClinicalTrials.gov API v2：NCT 编号、研究摘要、条件和更新时间。注册信息不等于试验成功或治疗有效。

开源项目

GitHub Search 提供年龄时钟、生物年龄、长寿 AI 和 Alzheimer 生物标志物等公开项目。项目条目代表软件信号，不代表经过临床验证。

旧版 AI雷达全部公开信息源

爱窝啦 AI雷达的 24 小时 AI 精选 JSON 会完整接入，并保留每条内容原来的站点和来源身份。当前内置分组包括 Official AI Updates、AI Breakfast、Follow Builders、TechURLs、Buzzing、Info Flow、BestBlogs、TopHub、Zeli、AI HubToday、AIbase、AI HOT、NewsNow，以及上游快照中存在的公开 OPML RSS。某个分组在单个 24 小时窗口内可能为零条。

这些上游候选完整保留在“全部来源”层；只有同时具备本地生命延续证据的条目才会进入核心或相关精选。上游失败不会阻断论文、试验、RSS、Papers.cool 和 GitHub 采集器。

实时状态

机器可读健康状态：source-status.json。失败来源会被记录，不会拖垮整轮更新。
